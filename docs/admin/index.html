Set up this device

Done once per phone or computer. Paste the site's GitHub access key, then choose the password you'll use to log in here. The key is kept only on this device, locked with your password. It is never published.

Where the access key comes from
  1. Signed in to GitHub as the account that owns this site, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: vivero-rosas menu admin. Expiration: 1 year.
  3. Repository access: Only select repositories → vivero-rosas.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate it, copy it (starts with github_pat_), and paste it above. Share it privately with anyone else who should edit the menu.

Admin login

Enter the admin password to edit the menu.

Phone, hours and socialsThe business phone shows on the site with a tap-to-call link. Leave it empty to show no phone. Hours are free text, for example "Tue–Sun 7am–3pm". Socials appear as a "Follow us" line only when filled in; a handle like @viveroderosas or a full link both work.

Menu itemsName and description in English and Spanish, plus the price. "Each" shows "each / c/u" after the price.

Lunch combosShown in their own box next to the menu.

CarnesThe meats customers can pick for tacos, tortas, burritos, sopes and gorditas.

Breakfast tacosName in English and Spanish. No prices are shown for these.

CateringShows in the catering section of every design. Leave the packages empty until you have them.

Notes for the admin
  • Saving publishes a new version of the site. GitHub takes about a minute to show it; refresh the site after that.
  • If you only fill in the English name, the Spanish side shows the English text.
  • Prices are shown exactly as typed, so include the dollar sign: $12 or $2.50.
  • Use the arrows to reorder. Changes are not saved until you press Save and publish.
