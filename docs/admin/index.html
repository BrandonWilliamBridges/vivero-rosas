Set up this device

Done once per phone or computer. Paste your own GitHub access key, then choose the password you'll use to log in here. The key is kept only on this device, locked with your password. It is never published.

Where the access key comes from

Each person who edits the menu gets their own key. Never share one key between people: with separate keys, one person's access can be removed without touching anyone else's.

  1. The account that owns this site makes the key: signed in to GitHub as that account, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: vivero-rosas menu admin – plus the editor's name. Expiration: 90 days or less.
  3. Repository access: Only select repositories → vivero-rosas. No other repository.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate it, copy it (starts with github_pat_), and give it only to that editor, in person or through a private channel. They paste it above on their own device.
  6. When the key expires, or someone stops editing the menu, delete their key on the same GitHub page and make a new one if needed.

Notes for the admin
  • Saving publishes a new version of the site. GitHub takes about a minute to show it; refresh the site after that.
  • If you only fill in the English name, the Spanish side shows the English text.
  • Prices are shown exactly as typed, so include the dollar sign: $12 or $2.50.
  • Use the arrows to reorder. Changes are not saved until you press Save and publish.
